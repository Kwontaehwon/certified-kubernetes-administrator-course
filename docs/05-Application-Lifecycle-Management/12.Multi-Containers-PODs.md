#### Multi-Container Pods
- 동일한 생명주기를 가지지만 따로 배포될 필요가 있는 경우 사용
  - ex) 웹서버 & Log Agent
### 기능
- 서로를 localhost로 참조 가능
- `volme sharing`을 설정하지 않고 동일한 volume에 접근 가능

  ![mcp](../../images/mcp.PNG)
  
- To create a new multi-container pod, add the new container information to the pod definition file.
  - `spec.containers` 아래는 배열 형식으로 받기 때문에 배열 값을 추가해주기만 하면 Multi-Container Pod
  ```
  apiVersion: v1
  kind: Pod
  metadata:
    name: simple-webapp
    labels:
      name: simple-webapp
  spec:
    containers:
    - name: simple-webapp
      image: simple-webapp
      ports:
      - ContainerPort: 8080
    - name: log-agent
      image: log-agent
  ```
